# Modi — aprender jugando

**Modi** es un proyecto educativo interactivo pensado para que niñas y niños practiquen habilidades iniciales de lectura y reconocimiento de números mediante preguntas sencillas, ilustraciones y pequeños retos.

El proyecto está creado y dirigido por su desarrollador, con apoyo de **ChatGPT (OpenAI, versión actual)** como asistente de inteligencia artificial para ideación, programación, revisión y documentación. Las decisiones del producto y su dirección corresponden a su creador.

## 🌱 Primera versión gratuita para la web

La primera versión está disponible gratuitamente en GitHub Pages:

**[Jugar a Modi](https://smlrom.github.io/modi-play-now/)**

El objetivo es ofrecer una experiencia accesible, amigable y progresiva para aprender jugando desde el navegador.

## 📚 Niveles y aprendizaje

La versión actual organiza los retos en cuatro categorías de dificultad:

- **Básica:** vocales, abecedario y números. Incluye nueve niveles iniciales.
- **Normal:** reconocimiento y formación de palabras.
- **Avanzada:** práctica mediante frases.
- **Difícil:** retos contrarreloj para poner a prueba lo aprendido.

En el modo difícil, cada partida dispone de un temporizador de 15 segundos. Las respuestas incluyen retroalimentación y las partidas terminan con un resultado de victoria o derrota.

## 🏆 Progreso, retos y skins

Modi permite consultar el progreso de juego y registrar resultados de los niveles. Completar niveles también ayuda a desbloquear apariencias para el personaje:

| Skin | Se desbloquea al completar |
|---|---:|
| 🐰 Modi clásico | Disponible desde el inicio |
| 🌾 Granjero | 4 niveles |
| 🚀 Astronauta | 8 niveles |
| 🤖 Robot | 12 niveles |
| 🧱 Bloques | 16 niveles |

Las skins desbloqueadas pueden seleccionarse y acompañan al personaje en la experiencia de juego.

### 💾 Guardado del progreso

El progreso y la skin seleccionada se guardan localmente en el navegador mediante el almacenamiento del dispositivo. En esta primera versión, el guardado **no está sincronizado en la nube ni vinculado a una cuenta**; por eso, puede no transferirse automáticamente a otro navegador o dispositivo. Se recomienda conservar el acceso desde el mismo navegador y evitar borrar sus datos si se desea mantener el progreso.

## 🔊 Opciones de juego

- Pantalla de progreso, tienda de skins y ajustes.
